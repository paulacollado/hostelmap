# HostelMap

## Descripción

HostelMap es una aplicación web interactiva para explorar y analizar la distribución territorial y la evolución temporal del sector de la hostelería en Madrid.

La aplicación permitirá visualizar establecimientos, comparar zonas y analizar diferentes características como categorías, valoraciones, precios y número de reseñas.

## Objetivos

- Integrar datos de establecimientos hosteleros de diferentes periodos.
- Analizar la distribución territorial de la hostelería en Madrid.
- Clasificar los establecimientos en categorías homogéneas.
- Analizar la evolución temporal de diferentes indicadores.
- Crear visualizaciones interactivas mediante Plotly.
- Desarrollar una aplicación web utilizando Dash.
- Construir un indicador agregado para facilitar la comparación territorial.
- Desplegar la aplicación online.

## Tecnologías

- Pandas
- NumPy
- Plotly
- Dash
- Git / GitHub
